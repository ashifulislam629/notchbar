# NotchBar

A small dashboard that lives at the top of your Windows screen. Hover over it or press **Ctrl+Shift+Space** to open.

Includes: clock, CPU/RAM, clipboard history with search, timer and stopwatch, file shelf (drag files in), notes, world clocks.

## Run from source
    npm install
    npm start

## Get the .exe from GitHub
Push this folder to a GitHub repo. Open the **Actions** tab, run **Build Windows app**, then download **NotchBar-windows** from the finished run. Unzip it and double-click the .exe.

Quit from the tray icon (bottom-right of the taskbar).
